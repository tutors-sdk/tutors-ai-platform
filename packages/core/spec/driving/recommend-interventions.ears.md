# RecommendInterventions

Derive lecturer-facing recommendations from verified insights.

- **RI-001** The RecommendInterventions use case shall derive recommendations only from insights whose evidence is complete and whose reasoning passed the evaluation harness.
- **RI-002** The RecommendInterventions use case shall name in every recommendation the insight, the evidence and the pedagogical rule that links them.
- **RI-003** The RecommendInterventions use case shall not change a course, a grade or a learner's experience.
